# Adobe Workfront Planning發行活動的構思空間

<span class="preview">此頁面上的資訊是指尚未普遍提供的功能。 它只能做為&#x200B;**創意空間Beta**&#x200B;程式的一部分。</span>

<span class="preview">如需詳細資訊，請參閱[開始使用Adobe Workfront Planning的創意空間](/help/quicksilver/planning/ideation/get-started-with-planning-ideation.md)。</span>

本文說明在&#x200B;**創意力空間Beta**&#x200B;期間為Workfront Planning創意力空間所發行的功能。 創意力專用開放Beta空間預定在2026年11月12日至2027年2月1日期間執行。

若為Adobe Workfront Planning發行版本，請參閱[Adobe Workfront Planning發行活動：文章索引](/help/quicksilver/product-announcements/product-releases/planning-release-activity/planning-release-activity-article-index.md)。

## Adobe Workfront Planning中創意力空間的新主區域

>[!NOTE]
>
>適用於創意空間測試版客戶的預覽和生產環境： 2026年11月25日

當您從Workfront華夫餅功能表存取創意空間時，現在會開啟「創意空間首頁」區域。 您可以從此重新開啟現有的畫布或建立畫布，因此您不再需要只為了移至現有畫布而使用空白畫布。 「首頁」區域會將您最近的畫布顯示為圖磚，在畫面下方列出所有其他畫布，並包含搜尋方塊。 當您在畫布內工作時，請使用新的「首頁」按鈕以返回「創意空間首頁」區域。

如需詳細資訊，請參閱[在創意力空間建立簡介](/help/quicksilver/planning/ideation/create-briefs-in-ideation-space.md)。
