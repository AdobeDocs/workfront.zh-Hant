# Adobe Workfront的2027年第一季度發行活動可用性限制

本文說明2027年第一季度推出的Workfront功能有限可用性。

<!--keep the sentence below for all future quarterly release pages-->

如需針對Adobe Workfront發行之所有有限可用性功能的清單，請參閱[Adobe Workfront有限可用性功能發行活動：文章索引](/help/quicksilver/product-announcements/product-releases/limited-availability-release-activity/limited-availability-release-activity-article-index.md)。

## 有限可用性功能的發行說明

本節包含新功能的發行說明。

### 展開或摺疊所有群組的功能

>[!NOTE]
>
>生產發行日期： 2026年10月27日

您現在可以使用第一欄頂端的箭頭圖示，展開或收合增強型清單中的所有群組。 這包括時程化報表。

之前，您只能展開或收合群組設定內的所有群組。

如需有關增強型清單的詳細資訊，請參閱[使用增強型清單](/help/quicksilver/workfront-basics/navigate-workfront/use-lists/enhanced-lists.md)。

### 檢視時程化報表上的選取專案

>[!NOTE]
>
>生產發行日期： 2026年10月27日

在時程化報表中建立新檢視的體驗已簡化，因此如果只有一個檢視型別可用，您就不必再選取檢視型別。

### 在時程化報表上釘選總計欄

>[!NOTE]
>
>生產發行日期： 2026年10月27日

您現在可以釘選&#x200B;**總計**&#x200B;欄，使其在時程化報表的右側保持可見。

此功能也可在使用「矩陣」檢視的其他畫面中使用，例如「人員配置計畫」。
