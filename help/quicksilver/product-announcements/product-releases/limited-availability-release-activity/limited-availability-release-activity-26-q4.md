# Adobe Workfront有限可用功能的2026年第四季發行活動

本文會說明將於2026年第三季度發行的Workfront功能有限可用性。

<!--keep the sentence below for all future quarterly release pages-->

如需針對Adobe Workfront發行之所有有限可用性功能的清單，請參閱[Adobe Workfront有限可用性功能發行活動：文章索引](/help/quicksilver/product-announcements/product-releases/limited-availability-release-activity/limited-availability-release-activity-article-index.md)。

## 有限可用性功能的發行說明

本節包含新功能的發行說明。

### 時間分段報表移轉至增強型清單

>[!NOTE]
>
>生產發行日期：待定

時間階段報表正在移轉至增強型清單格式，提供增強的檢視管理。 在增強型清單中，您可以快速設定偏好設定以篩選和分組資料，以及顯示或隱藏欄。 這些偏好設定會合併為「檢視」，您可加以儲存並與其他使用者共用。 您可以從一般範本建立報告，並使用檢視來組織報告結構並縮小資料範圍。

使用者在移轉前已在現有報表上設定的任何設定（篩選器、群組、欄可見度）都會保留，並轉換為&#x200B;**我的檢視**&#x200B;類別中的檢視。 任何有權存取報告的人都會自動將該檢視與其共用。

也會為每個報表型別建立預設檢視。 例如，在任務報告中，預設值命名為「時間分段任務預設檢視」。 系統管理員可以設定版面配置範本中每種報告型別的預設檢視。

>[!NOTE]
>
>系統中的現有資料不會變更。 只有資料的檢視在報表中有所變更。

如需有關檢視和增強型清單的詳細資訊，請參閱[使用增強型清單](/help/quicksilver/workfront-basics/navigate-workfront/use-lists/enhanced-lists.md)。
