# 2027年第一季度管理員增強功能

本頁說明管理員在2027年第一季度版本中對「預覽」環境所做的增強功能。 如上所述，這些增強功能將於生產環境中提供。

如需2027年第一季發行週期目前可用的所有變更清單，請參閱[2027年第一季發行概觀](/help/quicksilver/product-announcements/product-releases/27-q1-release-activity/27-q1-release-overview.md)。

## 移除附加自訂表單的許可權

>[!NOTE]
>
>預覽： 2026年10月29日
>生產快速發行： 2026年11月12日
>適用於所有人的生產： 2027年1月21日

共用自訂表單時，您現在可以為具有表單管理存取許可權的使用者設定許可權，以從表單附加至的物件中移除表單。

如需詳細資訊，請參閱[共用自訂表格](/help/quicksilver/administration-and-setup/customize-workfront/create-manage-custom-forms/share-access-to-a-custom-form.md)。

## 將自訂欄位標示為我的最愛

>[!NOTE]
>
>預覽： 2026年10月29日
>生產快速發行： 2026年11月12日
>適用於所有人的生產： 2027年1月21日

您現在可以在欄位清單或自訂表格設計工具中，將自訂欄位標示為我的最愛。 當您使用某些清單和報告（例如專案、任務和問題清單）並建立篩選器、檢視和分組時，最喜愛的欄位會出現在「建議」區段中可用欄位清單的最上方。

標籤為我的最愛欄位也會出現在表單設計器的欄位資料庫頂端。

如需詳細資訊，請參閱[建立自訂表格](/help/quicksilver/administration-and-setup/customize-workfront/create-manage-custom-forms/form-designer/design-a-form/design-a-form.md)。

## 變更格式時已在自訂欄位上驗證的值

>[!NOTE]
>
>預覽： 2026年10月29日
>生產快速發行： 2026年11月12日
>適用於所有人的生產： 2027年1月21日

現在，當您將現有的文字自訂欄位格式變更為數字或貨幣時，系統會檢查不相容的值。

如果欄位的現有值都是數字，則系統僅會更新欄位格式。 但是，如果任何現有值為非數值，系統會顯示警告訊息，指出當您儲存欄位時，系統會清除不相容的值。

如需詳細資訊，請參閱[建立自訂表格](/help/quicksilver/administration-and-setup/customize-workfront/create-manage-custom-forms/form-designer/design-a-form/design-a-form.md)。

## 變更記錄現在會追蹤畫布控制面板物件

>[!NOTE]
>
>預覽： 2026年10月29日
>生產快速發行： 2026年10月29日
>適用於所有人的生產： 2026年10月29日
>[!BADGE 不在排程]{type=Neutral}內

變更歷史記錄現在會記錄對畫布儀表板的變更。 您可以檢視誰建立、更新或刪除了儀表板或報表，以及他們何時進行該操作及變更了哪些內容。

若要開始追蹤畫布儀表板變更，您必須在「設定>變更追蹤>設定」中設定&#x200B;**儀表板**、**報表**&#x200B;和&#x200B;**報表設定**&#x200B;物件。

如需詳細資訊，請參閱[檢視及管理變更記錄](/help/quicksilver/administration-and-setup/add-users/create-and-manage-users/view-and-manage-change-history.md)。
