# 2027年第一季度發行時間範圍內的其他增強功能

本頁說明了2027年第一季度版本對預覽環境所做的增強功能。 如上所述，這些增強功能將於生產環境中提供。

如需2027年第一季發行週期目前可用的所有變更清單，請參閱[2027年第一季發行概觀](/help/quicksilver/product-announcements/product-releases/27-q1-release-activity/27-q1-release-overview.md)。

## 檢視增強型清單中的記錄總數

>[!NOTE]
>
>預覽： 2026年10月29日
>生產快速發行： 2026年11月12日
>適用於所有人的生產： 2027年1月21日

增強型檢視現在會顯示專案總數，而計數會在您套用篩選器、搜尋或變更檢視時自動更新。 專案計數一律會根據您的許可權反映完整的篩選結果。

如需詳細資訊，請參閱[使用增強型清單](/help/quicksilver/workfront-basics/navigate-workfront/use-lists/enhanced-lists.md)。

## 在增強型清單中更清楚顯示快速搜尋結果

>[!NOTE]
>
>預覽： 2026年10月29日
>生產快速發行： 2026年11月12日
>適用於所有人的生產： 2027年1月21日

當您在增強型清單中使用快速搜尋來尋找專案時，該清單會排除不符合搜尋的所有記錄，並僅顯示符合的專案。

在此增強功能之前，所有專案都會顯示，且反白顯示與搜尋結果相符的專案。

如需詳細資訊，請參閱[使用增強型清單](/help/quicksilver/workfront-basics/navigate-workfront/use-lists/enhanced-lists.md)。

## 更新增強型清單

>[!NOTE]
>
>預覽： 2026年10月29日
>生產快速發行： 2026年11月12日
>適用於所有人的生產： 2027年1月21日

已針對增強型清單進行下列變更：

* 您現在可以使用第一欄頂端的箭頭圖示，展開或收合增強型清單中的所有群組。 之前，您只能展開或收合群組設定內的所有群組。
* 建立新檢視時，如果只有一個檢視型別可用，您就不必再選取檢視型別。

如需詳細資訊，請參閱[使用增強型清單](/help/quicksilver/workfront-basics/navigate-workfront/use-lists/enhanced-lists.md)。

## 多個畫面已更新為增強型清單

>[!NOTE]
>
>預覽： 2026年10月29日
>生產快速發行： 2026年11月12日
>適用於所有人的生產： 2027年1月21日

下列Workfront清單現在使用增強型清單格式：

* 設定>介面>版面配置範本
* 設定>電子郵件>通知>事件通知與群組詳細資訊頁面>事件通知

部分或全部清單的更新包括以下內容：

* 清單的新外觀，包括顏色、格式和字型的更新。
* 在清單中建立新物件的選項已移至右上方，並顯示為藍色按鈕。
* 工具列已移除。 現在，當您選取表格中的一或多個物件時，動作列會以藍色顯示在清單底部。
* 某些欄可能已重新定位或移除，或新增了新欄。
* 部分確認和警告已移除或變更。
* 現在會自動儲存在某些清單中，而且可能已移除「儲存」按鈕。
* 部分增強型清單可讓欄重新命名或排序。
* 有些增強型清單包含欄管理員，可讓您新增及排列欄。 您可以在Workfront中依原生或自訂欄位選取欄。
* 表格儲存格內的圖示已由具有多個選項的「更多」功能表取代。

>[!NOTE]
>
>並非所有更新都可在所有清單上使用。

如需詳細資訊，請參閱[使用增強型清單](/help/quicksilver/workfront-basics/navigate-workfront/use-lists/enhanced-lists.md)。

## 在行事曆報告周檢視中顯示或隱藏小時

>[!NOTE]
>
>預覽： 2026年10月29日
>生產快速發行： 2026年11月12日
>適用於所有人的生產： 2027年1月21日

您現在可以在行事曆報告的「週」檢視中，顯示或隱藏當天的時數。 隱藏小時，以更簡單、更精簡的方式檢視您的一週，或是在您想要當日時間刻度時顯示它們。 使用行事曆右上角的切換功能，在兩個之間切換。

如需詳細資訊，請參閱[檢視行事曆報告和活動詳細資料](/help/quicksilver/reports-and-dashboards/reports/calendars/view-calendar-reports-and-event-details.md)。
