# 2027年第一季AI增強功能

本頁說明2027年第一季度發行版本對預覽環境所做的AI增強功能。 如上所述，這些增強功能將於生產環境中提供。

如需2027年第一季發行週期目前可用的所有變更清單，請參閱[2027年第一季發行概觀](/help/quicksilver/product-announcements/product-releases/27-q1-release-activity/27-q1-release-overview.md)。

## 設定攝入協調員預先建立的AI共同作業人員

>[!NOTE]
>
>預覽： 2026年11月12日
>生產快速發行： 2026年11月12日
>適用於所有人的生產： 2026年11月12日
>[!BADGE 並行發行]{type=Neutral}

管理員現在可以透過選取Adobe Native作為代理程式來源，將攝入協調員（預先建立的AI共同作業人員）設定為工作代理程式。 接著，使用者可以將工作代理指派給問題，以檢查其詳細資料、自訂表單及附件是否有遺失、不明確或不一致的資訊。 錄取協調員會張貼回饋意見，或在使用者核准後進行變更。

如需詳細資訊，請參閱[設定預先建立的AI共同作業人員](/help/quicksilver/administration-and-setup/set-up-workfront/configure-system-defaults/configure-prebuilt-ai-collaborators.md)。

## 使用Writer教戰手冊建立工作代理

>[!NOTE]
>
>預覽： 2026年11月12日
>生產快速發行： 2026年11月12日
>適用於所有人的生產： 2026年11月12日
>[!BADGE 並行發行]{type=Neutral}

您現在可以使用Writer教戰手冊來建立工作代理。 將Writer Playbook設定為工作代理後，您可以像指派使用者一樣，將其指派給Workfront中的工作。

如需詳細資訊，請參閱[設定AI共同作業人員](/help/quicksilver/administration-and-setup/set-up-workfront/configure-system-defaults/configure-ai-collaborators.md)。

## 工作代理程式：Adobe原生支援

>[!NOTE]
>
>預覽： 2026年11月12日
>生產快速發行： 2026年11月12日
>適用於所有人的生產： 2026年11月12日
>[!BADGE 並行發行]{type=Neutral}

為了更方便將AI支援的工作帶入您的工作流程，我們已新增Adobe Native作為工作代理程式的支援來源。

您現在可以建立使用CX Enterprise Coworker collaborator （由CX Enterprise Coworker Agent Orchestrator提供支援的Adobe代理程式）的工作代理程式，而不需要設定個別的外部平台或輸入外部認證。 這可讓團隊以更快的方式開始，同時保留相同的Workfront任務指派和執行模型。

安裝體驗現在也反映了Adobe原生和外部平台代理程式之間以來源為基礎的差異，包括每個選項的先決條件和設定流程。

可以使用工作註解中的@mention將原生代理程式新增至工作。

如需詳細資訊，請參閱[設定AI共同作業人員](/help/quicksilver/administration-and-setup/set-up-workfront/configure-system-defaults/configure-ai-collaborators.md)和[使用工作代理程式](/help/quicksilver/manage-work/tasks/assign-tasks/use-task-collaborators.md)。
