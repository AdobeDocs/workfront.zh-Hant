# Adobe Creative Cloud專案概觀

您可以直接從Adobe Photoshop、Illustrator和InDesign存取您的Workfront專案。 在Creative Cloud應用程式視窗左側的「專案」面板中，您無需離開應用程式即可開啟、編輯及儲存Workfront專案中的檔案。 您也可以直接將新檔案儲存至Workfront專案。

只有使用Adobe雲端儲存空間的專案才會和您的其他Creative Cloud專案一起出現在「專案」面板中。 面板會反映Workfront中檔案的資料夾結構。

當您儲存具有核准工作流程的檔案時，Workfront會建立新版本並保留核准歷史記錄。 當您儲存不含核准工作流程的檔案時，Workfront會更新最新版本。

## 先決條件

* 您的組織必須採用支援Adobe雲端儲存空間的Workfront版本。
* Workfront與Photoshop、Illustrator或InDesign必須有權使用同一個Adobe Identity Management System (IMS)組織。


## 您可以從Photoshop、Illustrator或InDesign的「專案」面板執行哪些操作

* 直接在Photoshop、Illustrator或InDesign中開啟Workfront專案資料夾和檔案。 您有權存取的任何Workfront專案會顯示在「專案」面板中。
* 編輯檔案並將變更儲存回Workfront專案。

如需詳細資訊，請參閱[在Creative Cloud應用程式中使用Workfront檔案](/help/quicksilver/documents/adobe-creative-cloud-projects/use-wf-documents-in-cc-apps.md)。

>[!NOTE]
>
>「專案」面板不支援舊版Workfront儲存專案。

## 相關整合

您也可以使用Adobe Cloud Drive來管理Workfront檔案，並自動將變更儲存至Workfront中的檔案。 如需詳細資訊，請參閱[Adobe Cloud Drive總覽](/help/quicksilver/documents/adobe-cloud-drive/adobe-cloud-drive-overview.md)。
